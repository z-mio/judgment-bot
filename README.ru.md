## ✨ Возможности

- 🧩 **Проверка при входе**: новый участник получает мут и должен нажать 😀, когда 🥵 сменится на 😀. При тайм-ауте или слишком раннем нажатии его исключают на 1 минуту. Администраторы могут принять или отклонить вручную кнопками ✅ / ❎
- 🏷️ **Метка неудачи**: не прошедшие проверку или не успевшие её пройти помечаются на 30 дней, их сообщения автоматически удаляются до успешной проверки
- 🔨 **Помощь участников**: участники, состоящие в группе от 30 дней, могут применять `/kick` к недавно вошедшим спамерам. Бот банит цель и удаляет её сообщения среди последних 100
- 🚨 **Анти-рейд режим**: включается автоматически при аномальном наплыве участников. Новые участники тихо исключаются, и бот не заваливает чат сообщениями с проверкой
- 🧹 **Автоочистка**: служебные сообщения о входе / выходе и сообщения гостевых ботов удаляются автоматически
- 💾 **Сохранение состояния**: сессии проверки хранятся в Redis и продолжаются после перезапуска

## 📖 Команды

| Команда | Кто | Описание |
| --- | --- | --- |
| `/kick` | Участники / админы | Ответом на спам-сообщение исключает отправителя. Ответом на сообщение канала банит канал (только админы) |
| `/unban <@username \| ID>` | Админы | Снимает бан и уведомляет пользователя в личных сообщениях |
| `/raid [on \| off]` | Админы | Показать статус и статистику анти-рейд режима / включить вручную / выключить |
| `/start` · `/help` | Все | Список команд |

<details>
<summary><b>🔨 Ограничения /kick</b></summary>

<br>

- Инициатор должен состоять в группе от 30 дней, цель — меньше 30 дней
- Кулдаун зависит от стажа инициатора в группе: чем дольше, тем короче:

  | Стаж инициатора | Кулдаун |
  | --- | --- |
  | ≥ 90 дней | 1 минута |
  | ≥ 60 дней | 30 минут |
  | ≥ 30 дней | 1 час |

- На администраторов ограничения не распространяются, они исключают сразу

</details>

<details>
<summary><b>🚨 Правила анти-рейд режима</b></summary>

<br>

| | Условие |
| --- | --- |
| **Автовключение** | ≥ 15 входов за 5 минут и доля прошедших ≤ 20% среди ≥ 10 завершённых проверок, **или** ≥ 20 входов за 1 минуту |
| **Пока включён** | Новые участники тихо исключаются на 1 минуту, текущие проверки сбрасываются. При включении в группу отправляется одно уведомление |
| **Автовыключение** | Включён ≥ 10 минут и < 5 входов за последние 5 минут |
| **Ручной режим** | Включённый через `/raid on` не выключается автоматически, выключите через `/raid off` |

</details>

## 🚀 Быстрый старт

**1. Создайте бота**: через [@BotFather](https://t.me/BotFather) получите `BOT_TOKEN`, на [my.telegram.org](https://my.telegram.org) — `API_ID` и `API_HASH`

**2. Добавьте в группу**: назначьте бота администратором как минимум с правами **Блокировка пользователей** и **Удаление сообщений**

**3. Настройте и запустите**

```shell
cp .env.example .env   # заполните параметры ниже
docker compose up -d
```

<details>
<summary>Без Docker? Запуск из исходников</summary>

<br>

Нужны Python 3.12+, [uv](https://docs.astral.sh/uv/) и работающий Redis

```shell
uv sync
uv run bot.py
```

</details>

## ⚙️ Настройка

| Переменная | Описание | По умолчанию |
| --- | --- | --- |
| `API_ID` | Telegram API ID | **Обязательно** |
| `API_HASH` | Telegram API Hash | **Обязательно** |
| `BOT_TOKEN` | Токен бота от BotFather | **Обязательно** |
| `ADMINS` | ID администраторов через запятую | Пусто |
| `BOT_PROXY` | Адрес прокси, на зарубежных серверах обычно не нужен | Пусто |
| `REDIS_HOST` | Хост Redis | `localhost` |
| `REDIS_PORT` | Порт Redis | `6379` |
| `REDIS_PASSWORD` | Пароль Redis | Пусто |
| `DEBUG` | `true` — включить отладочные логи | `false` |

> [!TIP]
> При развёртывании через `docker compose` настройки Redis подставляются автоматически, менять их обычно не нужно.

## 💬 FAQ

<details>
<summary><b>Почему не сделать проверку строже?</b></summary>

<br>

Никакая проверка не остановит живых спамеров, а спам-ботов останавливает и простая.

</details>

<details>
<summary><b>Почему нет модерации содержимого?</b></summary>

<br>

Модерация содержимого легко задевает обычных участников, особенно мемы, абсурдный юмор и сообщения, зависящие от контекста.

</details>

<details>
<summary><b>Спамеров слишком много?</b></summary>

<br>

Участники со стажем от 30 дней могут помочь через `/kick`. При массовом наплыве аккаунтов анти-рейд режим включается автоматически.

</details>
